# Poesia do Venâncio

## Alterações desta versão

1. O tema predefinido para novos visitantes é o modo claro.
2. Nas páginas individuais, a ligação junto à seta diz “Voltar ao início”.
3. A página do livro inclui um botão de partilha no cabeçalho.
4. A caixa de partilha apresenta WhatsApp, Email, Facebook, Telegram e Copiar ligação.
5. Em dispositivos compatíveis, surge ainda “Mais aplicações”, que abre o menu de partilha do sistema e permite escolher outras aplicações instaladas.

## Publicação

Substitua a pasta `poesia` no projeto e envie as alterações para o GitHub. O Netlify fará o novo deploy automaticamente.
